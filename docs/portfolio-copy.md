## 1. Aurex7 Trading Platform (public, live at aurex7.com)

**One-liner:** One account for trading, earning and token mining, built end to end.

**Summary (~60 words):**
Aurex7 combines spot and futures trading, Earn products, daily token mining and an ICO token sale in a single account. Oryan Techsol built the full platform: customer app, security layer and admin back office, with two-factor authentication and manual review of every withdrawal.

**Full description (~150 words):**
*Challenge:* The business wanted one account covering crypto mining, token sales and trading, instead of stitching together separate tools and logins.
*Solution:* We built Aurex7 end to end on Next.js, PostgreSQL and Prisma. Customers trade spot markets (market and limit orders across 280+ pairs) and a futures mode, use flexible and locked Earn products, mine the AX7 token daily with boost packages and referral bonuses, and take part in phased ICO sales.
*Security and control:* two-factor authentication, device and session control, manual review of every withdrawal, a full ledger entry for every balance change and an audit log of admin actions.
*Platform:* Web. *Industry:* Finance.

**Tags:** fintech, trading platform, Next.js, PostgreSQL, Prisma, custom software, admin back office

## How to fill directory fields (Clutch, GoodFirms, DesignRush)

| Field | Use |
|-------|-----|
| Project title | Titles above (anonymous title for private clients) |
| Service category | Custom software development / Web development / AI development |
| Project summary | Summary (~60 words) |
| Challenge / Approach | From "Full description": *Challenge* and *Solution* lines |
| Technologies | The technology line |
| Industry | The industry line |
| Project size / budget / timeline | Only if the client agrees; ranges are fine ("$25k–$50k") |
| Results / outcome | **Add a real, measured result**, e.g. "cut manual data entry from X to Y hours a week". If none exists yet, leave blank rather than invent one |
| Client review | Ask the client for a short testimonial or a verified review link |

## What would make these stronger (do when possible)

1. One measured result per project (time saved, orders handled, users, uptime).
2. A named quote from each client, with permission.
3. 2–3 screenshots per project (hide private data) for Behance and directories.
4. For public projects, a one-line link to the live site on every listing.
